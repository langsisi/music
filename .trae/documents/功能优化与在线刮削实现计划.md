# 功能优化与在线元数据刮削 — 实现计划

## Context（背景与目标）

用户在使用本音乐播放器（Avalonia / .NET 10，支持本地 / FTP / Navidrome 音源）时提出 4 项需求：

1. 底部控制栏与全屏「正在播放」中，**播放模式按钮（顺序/随机/列表循环/单曲循环）与收藏按钮的图标尺寸偏小**，与上一首/下一首不一致；三种播放模式状态之间的图标大小也不一致，需要统一。
2. 全屏「正在播放」右上角的**队列图标当前没有任何功能**，点击应弹出「正在播放列表」（播放队列），可看到当前队列并点击跳转。
3. **在线升级的服务器地址与令牌目前需用户在设置里手填**，发布后用户开箱不应需要配置。
4. 部分歌曲**缺少封面/歌词**，用户此前依赖 NAS 上部署的 `xhongc/music_tag_web` 刮削。希望 App 自身也能联网获取封面/歌词，并**支持选择数据源**。

预期结果：UI 按钮尺寸统一；「正在播放」可查看/跳转队列；开箱即可检测更新；可为缺封面/歌词的曲目联网刮削并本地缓存显示。

### 已确认的决策（来自用户）
- 刮削结果 **只缓存到本地并显示，不改动音乐文件**（适用于本地/FTP/Navidrome 三种音源）。
- 数据源接入 **网易云、QQ 音乐、酷狗、酷我、咪咕、iTunes**（全部）。
- 在线升级：**移除地址/用户名/令牌输入框，保留「检查更新」按钮与版本号显示**。
- 按钮尺寸统一：**底部播放条 + 全屏「正在播放」两处都改**。

## 四、在线封面/歌词刮削（item 4）

**目标**：对缺封面/歌词的曲目，按用户在设置中选择的数据源联网搜索，命中后把封面/歌词**缓存到本地并显示**，不改动源文件。

### 新增目录 `src/Music/Services/Metadata/`
- `IMetadataProvider.cs`：
  ```csharp
  public sealed record TrackQuery(string Title, string Artist, string Album);
  public sealed record MetadataCandidate(string ProviderId, string RemoteId, string Title,
      string Artist, string Album, string? CoverUrl, bool HasLyrics);
  public interface IMetadataProvider
  {
      string Id { get; }            // netease / qq / kugou / kuwo / migu / itunes
      string DisplayName { get; }
      bool SupportsLyrics { get; }
      Task<IReadOnlyList<MetadataCandidate>> SearchAsync(TrackQuery q, CancellationToken ct);
      Task<byte[]?> GetCoverAsync(MetadataCandidate c, CancellationToken ct);
      Task<string?> GetLyricsAsync(MetadataCandidate c, CancellationToken ct);
  }
  ```
- `MetadataHttpClient.cs`：共享 `HttpClient` 的封装，按请求注入各源所需的 `User-Agent` / `Referer` / `Cookie` / `csrf`（**不要**改全局默认头，Navidrome 也在用同一个 `HttpClient`，见 [ServiceCollectionExtensions.cs L40](file:///e:/Code/Avalonia/Music/src/Music/Services/ServiceCollectionExtensions.cs#L40)）。
- `MetadataScrapeService.cs`：编排单曲刮削。流程：选 provider → `SearchAsync(DisplayTitle, Artist, Album)` → 打分选最佳匹配 → 下载封面写 `AppPaths.CoversDir`（**文件名带内容哈希**，见障碍）→ 写回 `track.CoverPath` → 下载歌词写 `AppPaths.LyricsDir/<id>.lrc` → `LyricsService.Invalidate(track.Id)` → `_libraryStore.UpsertTracksAsync([track])` 落库 → 返回结果。
- `Providers/`：`NeteaseMetadataProvider`、`QqMetadataProvider`、`KugouMetadataProvider`、`KuwoMetadataProvider`、`MiguMetadataProvider`、`ItunesMetadataProvider`。

### 各数据源端点（可靠度已标注）

| 源 | 搜索 | 封面 | 歌词 |
|---|---|---|---|
| 网易云（可靠） | `GET https://music.163.com/api/search/get/web?s={kw}&type=1&limit=10` → `result.songs[].id/name/artists[0].name` | 搜索项 `album.picUrl` | `GET https://music.163.com/api/song/lyric?id={id}&lv=-1&kv=-1&tv=-1` → `lrc.lyric`（需 `Referer: https://music.163.com`） |
| QQ（可靠） | `GET https://c.y.qq.com/soso/fcgi-bin/client_search_cp?p=1&n=10&w={kw}&format=json` → `data.song.list[].songmid/songname/singer[0].name/albummid` | `https://y.gtimg.cn/music/photo_new/T002R300x300M000{albummid}.jpg` | `GET https://c.y.qq.com/lyric/fcgi-bin/fcg_query_lyric_new.fcg?songmid={mid}&format=json&nobase64=1` → `lyric`（**必须** `Referer: https://y.qq.com/`） |
| 酷狗（搜索稳，其余尽力） | `GET https://mobilecdn.kugou.com/api/v3/search/song?format=json&keyword={kw}&page=1&pagesize=10&showtype=1` → `data.info[].hash/songname/singername` | 尽力：`https://www.kugou.com/yy/index.php?r=play/getdata&hash={hash}` → `data.img` | 尽力：`https://m.kugou.com/app/i/krc.php?cmd=100&timelength={ms}&hash={hash}`（KRC 需转 LRC） |
| 酷我（搜索稳，其余尽力） | `GET https://search.kuwo.cn/r.s?all={kw}&ft=music&itemset=web_2013&client=kt&pn=0&rn=10&rformat=json&encoding=utf8` → `abslist[].MUSICRID/SONGNAME/ARTIST/ALBUM` | `https://img1.kuwo.cn/star/albumcover/{short}` | 尽力：`GET https://m.kuwo.cn/newh5/singles/songinfoandlrc?musicId={rid}` → `data.lrclist[].lineLyric` 拼 LRC |
| 咪咕（尽力） | `GET https://m.music.migu.cn/migu/remoting/scr_search_tag?keyword={kw}&type=2&rows=10&pgc=1` → `musics[].id/songName/singerName/cover` | 搜索项 `cover` | 尽力：`GET https://music.migu.cn/v3/api/music/audioPlayer/getLyric?copyrightId={id}` → `lyric` |

### 关键障碍与注意
- **封面缓存失效（必须处理）**：[PathToBitmapConverter.cs](file:///e:/Code/Avalonia/Music/src/Music/Converters/PathToBitmapConverter.cs#L19-L48) 按路径字符串缓存且不校验修改时间；若覆盖同名文件，UI 仍显示旧位图。故刮削封面文件名须**随内容变化**，如 `{trackId}_{sha1前8位}.jpg`。
- 移动端：`AndroidManifest.xml` 已开启 `usesCleartextTraffic`，HTTP 明文可用；仍优先 HTTPS。
- 限流/风控：网易云/QQ 需带 `Referer`，失败退避并静默返回；酷狗/酷我/咪咕为移动端私有 API，可能变动，需容错。
- iTunes 无歌词：选中时 UI 提示「仅封面」。
- 不写回文件：无需 TagLib 写标签；只写 `CoversDir`/`LyricsDir` 与曲库 DB（`UpsertTracksAsync` 已确认会更新 `CoverPath` 列，见 [SqliteLibraryStore L111-L130](file:///e:/Code/Avalonia/Music/src/Music/Services/Library/SqliteLibraryStore.cs#L111-L130)；收藏表独立，不受影响）。
